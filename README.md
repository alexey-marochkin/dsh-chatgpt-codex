# ChatGPT - Codex

Подписка ChatGPT в DeepSeek Harness: модели аккаунта, остатки лимитов и управление доступными сбросами. Приложение и CLI Codex не нужны.

[Описание и скриншоты](https://devos.aicent.ru/dsh-plugins/chatgpt-codex/) · [Каталог Developer OS](https://devos.aicent.ru/dsh-plugins/)

## Установка

Проверено с **DSH 0.2.2-rc.3 на Windows**. Другие версии пока не заявлены как совместимые.

1. В разделе «Плагины → Экспериментальные» включите **Custom plugin indexes**.
2. Во вкладке **Discover / Обзор → Add index source** добавьте адрес:

   ```text
   https://devos.aicent.ru/dsh-plugins/index.json
   ```

3. Выберите каталог **Developer OS**, найдите **ChatGPT - Codex** и установите. Следуйте инструкции DSH; при необходимости полностью перезапустите приложение.
4. Откройте «Настройки → Модели → Добавить поставщика моделей → ChatGPT - Codex».
5. Нажмите «Войти через ChatGPT», завершите вход в открывшемся браузере и нажмите «Применить». Выберите модель в чате.

Индекс фиксирует коммит установки. Desktop использует собственный управляемый профиль, а не профиль `web`.

После входа и применения настроек попросите в диалоге, например, «Нарисуй маяк в тумане». Инструмент `chatgpt_codex_generate_image` создаёт новое изображение через `gpt-image-2` по подписке подключённого аккаунта ChatGPT и возвращает его вложением DSH. Генерация расходует доступный аккаунту лимит изображений.

В локальной рабочей области агент копирует файл в рабочую папку и выводит изображение в ответе. Карточку файла добавляет штатный инструмент `present`. Имя файла можно задать в запросе. Если имя пропущено, модель предложит его по содержанию изображения.

## Установка через CLI (npx)

Для установки в профиль `web` скопируйте команду со [страницы выпуска в каталоге DevOS](https://devos.aicent.ru/dsh-plugins/chatgpt-codex/#cli-title). Она указывает на ту же ревизию, что и Discover.

## Возможности

- Вход ChatGPT и модели, доступные аккаунту и встроенному адаптеру DSH.
- Кэш каталога на 24 часа: после перезапуска модели доступны сразу, каталог обновляется в фоне.
- Зелёный статус подключения в настройках моделей.
- Остаток недельного лимита рядом с сообщением, только для моделей коннектора.
- Уменьшающаяся дуга кругового индикатора при свежем недельном остатке меньше 20% красная, от 20% включительно до 30% — жёлтая. Текст и фоновое кольцо не перекрашиваются. При 30% и выше цвет дуги обычный; для неизвестных или устаревших данных дуга не отображается.
- Доступный сброс с истечением в ближайшие 48 часов вызывает предупреждение рядом с индикатором: дата, просмотр списка и закрытие. Автоматического расходования нет.
- По нажатию на индикатор — доступные окна лимитов, остатки и время обновления.
- В настройках — доступные сбросы, сроки действия и серверная история.
- Использование выбранного сброса только после отдельного подтверждения.
- Русский и английский интерфейсы; время в часовом поясе компьютера.

## Данные и ограничения

Авторизация сохраняется в credentials DSH; токены не передаются в интерфейс и не записываются в журнал. Плагин обращается напрямую к сервисам авторизации OpenAI и backend ChatGPT. Файлы авторизации установленного Codex не используются.

Каталог сохраняется в `$DSH_HOME/cache/chatgpt-codex/catalog.json`: только идентификаторы и названия моделей, время получения и хеш идентификатора аккаунта. После перезапуска свежий кэш используется только при наличии входа в тот же аккаунт и пересекается с моделями установленного адаптера. Фоновое обновление запускается при первом запросе списка моделей; ошибка сети не удаляет ещё действующий кэш. Просроченный или повреждённый файл игнорируется. «Обновить модели» повторяет запрос вручную; выход и новый успешный вход очищают прежний кэш. Кэш не даёт автономного доступа к моделям: для ответов нужна сеть и действующая авторизация.

Модели и лимиты определяет сервер аккаунта. Плагин показывает распознанные данные ответа, не вычисляет квоту по числу сообщений и не покупает дополнительные кредиты. Внутренние API ChatGPT и интерфейсы DSH могут измениться.

Вход с нуля, ответы модели, лимиты после перезапуска и серверная история проверены на рабочей установке. **Реальное использование сброса пока не проверялось**: отправка запроса, подтверждение, отмена и защита от повторов покрыты тестами с подменой сети. Это первый публичный выпуск.

«Отключить» удаляет локальную авторизацию плагина. Разрешение на стороне OpenAI при необходимости отзывается отдельно в настройках аккаунта.

## Проверки и диагностика

Проверка истекающих сбросов выполняется при открытом чате с выбранным ChatGPT - Codex и успешном получении лимитов, не чаще раза в минуту. Уведомление относится только к доступным, ещё не просроченным сбросам из свежего ответа сервера. На выключенном компьютере или при закрытом DSH уведомлений нет; при следующем открытии показываются актуальные сбросы в пределах 48 часов.

Отметки выдачи предупреждений хранятся в `$DSH_HOME/storages/chatgpt-codex/reset-warnings.json` как хеши пар «аккаунт — сброс» и сохраняются при выходе и перезапуске. Отметка записывается до отправки уведомления клиенту: это исключает повтор, но при обрыве связи в этот момент уведомление может не отобразиться. Список доступных сбросов всегда можно открыть в настройках. Ошибка чтения или записи отметок не создаёт повторных предупреждений и не мешает показу лимитов.

```sh
npm test
```

События коннектора сохраняются в `$DSH_HOME/logs/dsh.log` в формате JSON Lines, с ротацией при 2 МиБ. Токены, коды и адреса OAuth в журнал не попадают. При сообщении об ошибке укажите версии DSH и плагина, действие и текст ошибки; не публикуйте файлы credentials.

## Диагностика каталога и скорость

Раздел «Каталог моделей и скорость» показывает источник (сервер/кэш), время получения, последнюю ошибку и видимые модели аккаунта. Неизвестные адаптеру модели отмечены отдельно и не добавляются в выбор модели автоматически.

Скорость сохраняется для каждой модели в настройках DSH: обычная (`default`), Fast (объявленный каталогом `priority` или `fast`), Ultrafast (`ultrafast`). Ускоренные режимы доступны только по метаданным сервера; старое поле `additional_speed_tiers` также поддерживается. Настройка применяется к следующим запросам во всех чатах. Если выбранный режим исчезает из каталога, используется обычный. Ускоренные режимы могут быстрее расходовать квоту; фактическое обслуживание определяет сервер.

Параметр `service_tier` добавляется через штатный `onPayload` pi-ai после преобразований `streamSimple`; рассуждения и транспорт остаются штатными. Это необходимо для DSH 0.2.2-rc.3 / pi-ai 1.3.0, где профиль адаптера не передаёт скорость напрямую. Кэш хранит только разрешённые идентификаторы скоростей.

### Рассуждения и ускорение (0.7.0-local.7)

Окно «Каталог и режимы моделей» разделяет уровень рассуждения и ускорение. Доступные усилия берутся из `supported_reasoning_levels` и пересекаются с возможностями pi-ai 1.3.0; они передаются в штатный селектор DSH. Пока сервер не объявил уровни, список настроек содержит только «По умолчанию». Неизвестные адаптеру уровни не выдаются за поддерживаемые.

Настройка рассуждения по умолчанию сохраняется для модели; явный выбор в чате имеет приоритет. Кнопка молнии показывается только при наличии Fast, исходно выключена и снабжена подсказкой о повышенном расходе квоты. Выбранное состояние сохраняется. Ранее описанный список скоростей заменён этими двумя независимыми элементами.

### Переключатель Fast в чате (0.7.0-local.9)

Готовая иконка Lucide Zap используется в настройках и в штатном меню выбора модели (`conversation.input.model.options`). Контур кнопки виден при наведении; клавиатурный фокус выделяется отдельно. Выключенная молния контурная, включённая — залитая. Подсказка сообщает о повышенном расходе квоты. Переключатель показывается только для выбранной поддерживаемой модели ChatGPT - Codex с объявленным Fast и заблокирован, когда DSH запрещает изменение выбора. Режим общий для модели во всех чатах, синхронизируется с настройками. Нажатие не отправляет запрос генерации.
